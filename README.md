# BioStove Insight

เว็บ dashboard ต้นแบบสำหรับสาธิตแนวคิดระบบ IoT ติดตามการใช้งานเตาชีวมวล ใช้ข้อมูลจำลองทั้งหมด เหมาะสำหรับทำคลิป Project Proposal รอบแรกก่อนจัดซื้ออุปกรณ์จริง

## เปิดดูบนเครื่อง

โปรเจกต์นี้เป็น static site ไม่มี dependency และไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
cd /workspace/-
python3 -m http.server 4173
```

จากนั้นเปิด `http://localhost:4173`

หากต้องการให้คนอื่นเปิดดูจากที่ไหนก็ได้ ให้นำไฟล์ทั้งหมดในโฟลเดอร์นี้ไป deploy เป็น static site บน GitHub Pages, Netlify หรือ Vercel ได้ทันที โดยไม่ต้องตั้งค่า build command หรือ environment variable

## ฟังก์ชันในต้นแบบ

- แผนที่จำลองเตา 60 จุด พร้อมสถานะกำลังใช้งาน / พร้อมใช้ / Offline
- คลิก marker เพื่อดูข้อมูลเตา อุณหภูมิ และ sensor ID
- กราฟอุณหภูมิย้อนหลัง 24 ชั่วโมง พร้อมเส้นเกณฑ์ 100°C
- ค้นหาเตาและกรองตามสถานะ
- ตารางกิจกรรมล่าสุด และปุ่ม refresh ข้อมูลจำลอง
- ป้ายกำกับชัดเจนว่าเป็น `Prototype • Simulated Data`
- ส่วน CO₂ ระบุ `Model under development` เพื่อไม่สื่อว่าเป็นผลทดลองจริง

## หมายเหตุสำหรับการประกวด

ตัวเลข อุณหภูมิ ตำแหน่งเตา และสถานะทั้งหมดเป็นข้อมูลสมมติสำหรับสาธิตแนวคิดระบบเท่านั้น ไม่ใช่ข้อมูลจากภาคสนามจริง เมื่อพัฒนาใช้งานจริงจึงค่อยเชื่อม ESP32, temperature sensor, database และ emission-factor model
